# demo_redis_vb_net

Projeto demonstrativo de integração entre VB.NET e Redis para armazenamento de dados em estrutura chave-valor e utilização de cache em memória.

## Sobre o Projeto

Projeto demonstrativo de integração entre VB.NET e Redis para armazenamento de dados em estrutura chave-valor e utilização de cache em memória.

## Tecnologias Utilizadas

- VB.NET
- StackExchange.Redis
- Redis Server

## Funcionalidades

- Gravação de valores com SET
- Consulta de valores com GET
- Definição de tempo de expiração (TTL)
- Demonstração de estruturas de dados em memória e operações de cache, conforme implementado

## Arquitetura do Projeto

Arquitetura de integração com um armazenamento chave-valor em memória. A aplicação VB.NET utiliza o cliente StackExchange.Redis para se comunicar com o servidor Redis.

## Banco de Dados

Redis, utilizado como armazenamento chave-valor em memória.

## Como Executar

1. Clone este repositório.
2. Verifique a versão do .NET necessária pelo projeto.
3. Inicie uma instância do Redis Server.
4. Configure o endereço e a porta do servidor Redis na aplicação.
5. Restaure os pacotes NuGet, compile e execute o projeto.
6. Teste as operações de gravação, leitura e expiração de chaves.

## Aprendizados

- Integração de aplicações VB.NET com Redis.
- Operações chave-valor com SET e GET.
- Utilização de TTL para expiração de dados.
- Conceitos de cache e armazenamento em memória.
